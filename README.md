# UDP通信测试工具

## 项目简介

这是一个基于C# WinForms开发的UDP通信测试工具，使用.NET Framework 4.7.2。该工具支持多通道UDP通信，可用于测试UDP数据的发送和接收功能。

## 主要功能

### 1. 多通道UDP支持
- 支持最多16个UDP通道
- 每个通道独立配置本地IP、端口和目标IP、端口
- 支持同时启动/停止所有通道

### 2. 实时数据收发
- 异步接收UDP数据包
- 支持手动发送文本消息
- 实时显示收发日志和时间戳
- 自动处理编码转换（UTF-8）

### 3. 用户友好界面
- 基于SunnyUI美观界面
- 多选项卡界面，每个通道独立显示
- 实时状态监控和日志显示
- 支持清除发送/接收区域

## 系统要求

- Windows 7/8/10/11
- .NET Framework 4.7.2 或更高版本
- 内存：至少 512 MB RAM
- 磁盘空间：至少 50 MB 可用空间

## 快速开始

### 1. 编译和运行

1. 打开 `UDP.sln` 解决方案文件
2. 使用 Visual Studio 2017 或更高版本编译
3. 运行编译后的可执行文件

### 2. 配置UDP通道

程序会自动创建默认配置文件：`ConfigFile/BUS/Device/UDP/UDPChannelConfig.csv`

配置文件格式：
```csv
序号,通道名称,通道ID,本地IP,本地端口,目标IP,目标端口
1,UDP通道1,UDP_CH_01,127.0.0.1,8001,127.0.0.1,9001
2,UDP通道2,UDP_CH_02,127.0.0.1,8002,127.0.0.1,9002
...
```

### 3. 使用步骤

1. **启动应用程序**
   - 程序会自动加载UDP通道配置
   - 显示16个通道选项卡

2. **开始测试**
   - 点击"开始测试"按钮启动所有UDP通道
   - 程序会显示每个通道的启动状态

3. **发送数据**
   - 在任意通道选项卡的发送区域输入文本
   - 点击"发送"按钮发送UDP数据包
   - 发送日志会显示在接收区域

4. **接收数据**
   - 程序会自动接收UDP数据包
   - 接收的数据会实时显示在接收区域
   - 包含时间戳和来源地址信息

5. **结束测试**
   - 点击"结束测试"按钮停止所有UDP通道
   - 或直接关闭程序

## 配置说明

### UDP通道配置参数

| 参数 | 说明 | 示例 |
|------|------|------|
| 序号 | 通道编号 | 1 |
| 通道名称 | 通道显示名称 | UDP通道1 |
| 通道ID | 通道唯一标识符 | UDP_CH_01 |
| 本地IP | 本地绑定IP地址 | 127.0.0.1 |
| 本地端口 | 本地绑定端口 | 8001 |
| 目标IP | 目标服务器IP地址 | 127.0.0.1 |
| 目标端口 | 目标服务器端口 | 9001 |

### 默认配置

程序默认创建16个UDP通道：
- 本地端口：8001-8016
- 目标端口：9001-9016
- 所有通道都使用本地回环地址（127.0.0.1）

## 测试方法

### 1. 本地回环测试

使用网络调试工具（如NetAssist）：
1. 启动网络调试工具
2. 创建UDP服务器，监听端口9001
3. 在应用程序中启动测试
4. 在通道1中发送消息
5. 观察网络调试工具是否收到数据

### 2. 两台机器测试

1. 修改配置文件中的IP地址
2. 确保两台机器网络连通
3. 确保防火墙允许UDP通信
4. 按照本地回环测试步骤进行

### 3. 多通道测试

1. 启动多个网络调试工具实例
2. 分别监听不同端口（9001-9016）
3. 在不同通道选项卡中发送消息
4. 验证每个通道的独立性

## 故障排除

### 常见问题

1. **端口占用错误**
   - 检查端口是否被其他程序占用
   - 修改配置文件中的端口号
   - 重新启动程序

2. **配置文件加载失败**
   - 检查配置文件格式是否正确
   - 确保CSV文件编码为UTF-8
   - 查看控制台输出的错误信息

3. **发送失败**
   - 检查目标IP和端口是否正确
   - 确保网络连接正常
   - 检查防火墙设置

4. **接收不到数据**
   - 检查本地IP和端口配置
   - 确保没有端口冲突
   - 检查数据发送端的配置

### 日志信息

程序会在控制台输出详细的日志信息：
- 配置加载状态
- 通道启动/停止状态
- 数据收发记录
- 错误信息
